# config设置内容

### 设置1
是否启用`lolomicalc 基础`计算
~~~~~~~~~~YAML
lolomicalc: true
~~~~~~~~~~
<details><summary>可用的内容 false true</summary>

`true` 启用

`false` 禁用

### 设置2
设置自动刷新预设面板的版本
~~~~~~~~~~YAML
panelmodel: 1 
~~~~~~~~~~

<details><summary>可用的内容 0 1 其他</summary>

`0` 用户自行修改的预设面板

`1` lolomi-calc默认的预设面板

</details>
